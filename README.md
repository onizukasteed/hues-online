# Hues & Cues Online

เกมทายสีจากคำใบ้ เล่นกับเพื่อน/ครอบครัว 3-10 คน: **จอทีวี/คอมเป็นกระดานสี 480 ช่อง, มือถือเป็นตัววางหมาก**
(Next.js 14 + Upstash Redis, deploy บน Vercel)

## กติกา
1. ผู้ให้คำใบ้ได้สีลับ 4 สี เลือก 1 สี แล้วให้คำใบ้ **คำเดียว** (ห้ามบอกชื่อสี/พิกัด)
2. ทุกคนวาง **หมากแรก** บนมือถือ (ลับ จนทุกคนวางครบ แล้วหมากแรกขึ้นกระดาน)
3. ผู้ให้คำใบ้ให้คำใบ้ที่ 2 **ไม่เกิน 2 คำ** แล้วทุกคนวาง **หมากที่สอง**
4. เฉลย: หมากตรงเป้า 3 แต้ม · ติดกัน (กรอบ 3×3) 2 แต้ม · ห่าง 1 ช่อง (กรอบ 5×5) 1 แต้ม
   ผู้ให้คำใบ้ได้ 1 แต้มต่อหมากที่อยู่ในกรอบ 3×3
5. ทุกคนผลัดกันให้คำใบ้ (3 คน = 3 ครั้ง, 4-6 คน = 2 ครั้ง, 7+ = 1 ครั้ง ปรับได้ในล็อบบี้) คะแนนรวมสูงสุดชนะ

## ตั้งค่า
`lib/config.js` (จำนวนผู้เล่น ความยาวคำใบ้, จำนวนรอบ) · `lib/colors.js` (สูตรสีของกระดาน)

## รัน/ดีพลอย
- Vercel: import repo นี้ แล้วเชื่อม Upstash Redis (Storage) ให้โปรเจกต์ (ตัวแปร `KV_REST_API_*` หรือ `UPSTASH_REDIS_REST_*`) จากนั้น Redeploy
- Redis key ขึ้นต้น `hc:` ใช้ฐานข้อมูลร่วมกับเกมอื่นได้
- รันในเครื่อง: `npm i && npm run dev` (ไม่มี Redis จะใช้หน่วยความจำชั่วคราว)
- ทดสอบ engine: `node scripts/test.mjs`
